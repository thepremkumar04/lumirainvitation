# Lumira — Digital Wedding Invitations

Lumira's main commercial landing page for international wedding-invitation clients.

## Positioning

**Luxury digital wedding invitations.**

Primary message: **Your wedding deserves more than a PDF.**

## Stack

- React 19
- Vite
- Framer Motion
- Lucide React
- Mobile-first CSS

## Main conversion flow

Instagram → Landing page → Live invitation → Pricing → Enquiry / WhatsApp

## Live invitation examples

- Manaswini & Dinesh — https://manaswini-dinesh-wedding.vercel.app/
- Sriya & Ajay Reddy — https://sriya-ajayreddy.vercel.app/

- Pradyumna & Srideepika — https://pradyumnaandsrideepika.vercel.app/

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

- The landing page is designed mobile-first and enhanced for desktop.
- The enquiry form uses the existing Formspree endpoint from the project.
- `/privacy` and `/terms` remain available.
